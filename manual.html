BlindSpot permits one running instance per user. Starting it again reports that BlindSpot is already running.

BlindSpot manual

Build 2026.9.4

BlindSpot is a portable, keyboard-first Spotify client for Windows and macOS.

Main interface

Use Tab and Shift+Tab to move throughout the interface. Enter opens an album, artist, playlist, or podcast, and plays a track or episode. Backspace returns to the previous remembered list position. A horizontal tab-bar, as well as a menu bar, is where the program's features are located

Keyboard commands

  • Ctrl+1 through Ctrl+9: Search, Liked Songs, Queue, Playlists, Recently Played, Audiobooks, Podcasts, Saved Albums, and Discover respectively.
  • Ctrl+B: open Bookmarks. Ctrl+Shift+G: search for concerts. Both are in the File menu and open in their own window; playback keys still work there.
  • Ctrl+Tab and Ctrl+Shift+Tab: cycle through the main tabs.
  • Ctrl+F: focus the search box.
  • Ctrl+Comma: open Preferences.
  • Enter: open a container, or play a track or episode.
  • F4: play the focused track, playlist, album, or artist. When no list has focus, F4 plays the song remembered from your last session.
  • F5: restart current track. Double-press within 0.5 seconds to move to the previous track immediately.
  • F6 / F8: seek backward and forward five seconds.
  • Shift+F8 / Shift+F6: jump to the next or previous lyric section (verse or chorus). BlindSpot finds sections from the gaps between lines in the synced lyrics, so this works only for songs that have them. Preferences has an option, off by default, to speak the section number after each jump.
  • F7: pause or resume. After launch, F7 also starts a remembered track when playback memory is enabled.
  • F9: next track.
  • Left bracket then right bracket: mark the start and end of a cart while a song is playing. Press Alt+1 through Alt+9 to assign the marked section.
  • Alt+1 through Alt+9: play the corresponding cart when no marked section is waiting to be assigned. Use File, Manage carts to preview or clear saved carts. Repeat One loops the current cart; Repeat All advances through populated carts in number order and wraps around.
  • Shift+F4 / Shift+F5: decrease and increase volume by five percent.
  • Shift+F7: mute or restore previous volume. Preferences can turn off the spoken volume percentage, which is on by default.
  • Space: pause or resume playback, except when focus is in a control that uses Space itself, such as a button, radio button, checkbox, or edit field.
  • Shift+Space: play from the current line in Lyrics view.
  • Ctrl+Q: queue selected track or tracks.
  • Ctrl+L: like or unlike selected track.
  • Ctrl+Shift+L: like or unlike the currently loaded track.
  • Ctrl+Shift+A: copy the selected track or marked tracks to an editable playlist, preserving their displayed order.
  • Ctrl+Shift+N: create playlist.
  • Ctrl+Shift+B: bookmark current playback position.
  • Ctrl+Shift+O: open the focused track's album, or the currently playing track's album when no list item has focus.
  • Ctrl+Shift+D: choose a Spotify Connect playback device.
  • Ctrl+R: cycle repeat mode.
  • Ctrl+S: toggle shuffle.
  • Ctrl+J: jump to playback time.
  • Ctrl+Shift+J: open sleep timer.
  • Ctrl+Shift+I: speak current track name.
  • Ctrl+Shift+U: speak upcoming track.
  • Ctrl+Y: retrieve lyrics for the focused playable item, or for the current track when focus is elsewhere.
  • Ctrl+Shift+T: speak total track time.
  • Ctrl+Shift+E: speak elapsed time.
  • Ctrl+Shift+R: refresh the current view.
  • On macOS, Option+M: open actions for the selected item.
  • Ctrl+Enter: open the focused track's album.
  • Delete: remove the selected playlist, or track from Liked Songs.
  • Delete inside a playlist: remove the selected track when editable.
  • Backspace or Alt+Left: return to the previous remembered view.
  • Shift+F10 or the Applications key: open item actions.

Library and playlist views provide a Filter this list edit box immediately before Now Playing in the Tab order. It searches the complete loaded list using the title, artist or publisher, and album or show name. Matching ignores case and common diacritics. Clear the edit box to restore every item. In an open playlist, F4 plays the visible filtered sequence beginning with the focused track.

The View, Sort by submenu can temporarily order supported collection views by Original order, Title, Artist, Album, Duration, or Date added when Spotify provides that field. Choose Descending in the View menu to reverse the selected sort. This changes only the displayed view and never rewrites the saved playlist. Queue and Recently Played are not sortable because their sequence has meaning.

Search results

Choose Related albums from an album's context menu, or while browsing its tracks, to open a deduplicated list of related albums. Enter opens a result, F4 plays it, and Backspace returns to the originating album or collection.

A category search initially displays up to 20 results. When Spotify has more matches, choose Load more results at the end of the list to append the next page. The separate editable Genre field browses community-tagged Songs, Albums, or Artists. Choose a supplied tag or type another; the ordinary Search query can optionally narrow those results. BlindSpot labels their Last.fm origin and resolves each result to Spotify before offering playback or library actions.

You do not need to know a tag's name. Open the context menu on a song or artist and choose Browse genres (Last.fm). BlindSpot lists that item's strongest community tags, each with Last.fm's own weight out of 100, and opens the one you choose as an ordinary Genre search for songs or artists respectively. Tags that merely repeat the artist or title, name a year, or describe opinion rather than genre, such as seen live, are omitted. These are community tags, not an official genre classification, and a track with few listeners may have none.

Finding covers

Open the context menu on a song and choose Find covers (MusicBrainz) to list other artists' recordings of the same song. MusicBrainz is a free, open music database. It links all recordings of a song together and marks which ones are covers, which Spotify does not provide.

The list opens in the Search tab, and Backspace returns to where you were. Live, video and karaoke recordings, and the artist of the song you started from, are left out. Recordings MusicBrainz marks as covers come first, in alphabetical order by artist, and their row ends with cover. Next come other recordings of the same song, then recordings with the same title that MusicBrainz has not yet linked to the song, which is common for recent releases; those are checked against the length of your track. If you start from a cover, the original artist's recording appears too. Novelty versions such as 8-bit arrangements are listed last. MusicBrainz has no popularity ranking, so the order does not reflect how well known a version is.

A lookup takes up to about 20 seconds, because MusicBrainz asks programs to make no more than one request a second. For a very popular song BlindSpot reads only the first 300 of its recordings and the status line says how many were checked. If MusicBrainz does not know the song, or has no song entry for it, BlindSpot tells you instead of showing an empty list.

Rows show the artist, title and year. A version is looked up on Spotify only when you play, queue, like or open the menu for it, as in Discover charts. MusicBrainz lists many recordings that are not on Spotify, so you may be told a version was not found.

Playlists

Followed playlists that cannot be edited are announced as read only. Enter opens a focused playlist. F4 plays the focused playlist, or starts at the focused song when browsing one. Playback continues from selected track to the end.

Use control+Space (or VoiceOver selection commands) to select multiple tracks. Use Ctrl+A on Windows and Linux, or Command+A on macOS, to select every track in the list. Select all is also available from the Edit menu and the list context menu. Ctrl+Q adds all marked songs to the queue. Delete removes the focused song from an editable playlist after confirmation. In the list of playlists, Delete removes the focused playlist from your library after confirmation.

Ctrl+C on Windows and Linux, or Command+C on macOS, copies the marked tracks to BlindSpot's playlist clipboard. Ctrl+X or Command+X cuts marked tracks from an editable playlist. Open the destination playlist and use Ctrl+V or Command+V to paste. Cut tracks remain in the source until the destination addition succeeds.

A track's context menu can open or start a similar-track mix provided by Last.fm, or append it after the current queue. Opening the mix displays up to 50 candidates in pages of 20 without changing playback; starting it plays the first matched page while the remaining candidates are prepared and appended in the background. BlindSpot starts one track and queues the rest so Spotify does not loop a multi-track playback context. When about ten queued mix tracks remain, BlindSpot uses the current track to find and append another deduplicated batch. Playing an unrelated item ends the continuous mix. Duplicate Spotify matches are removed throughout the session. Repeat is switched off before starting a mix. Ctrl+Shift+M opens a mix for the focused track and Ctrl+Shift+P starts it. The Go menu provides equivalent actions for the currently playing track.

The playlist context menu provides Open, Play, New playlist, Rename for playlists you own, and Remove from library.

While browsing a playlist you own, the selected track's context menu contains a Move submenu. Tracks can be moved up, down, to the top or bottom, or to a numbered position. Focus follows the moved track and BlindSpot announces its new position. Reordering is not offered for playlists owned by someone else.

Type two or more letters quickly in any item list to jump to an item beginning with that prefix. The prefix resets after a short pause.

A playlist track's context menu provides Copy to playlist. Editable source playlists also provide Move to another playlist. These commands apply to marked tracks, or the focused track when nothing is marked. A move removes source tracks only after they are added to the destination.

The same owned-playlist track menu provides Find alternate versions. BlindSpot searches for other recordings by the primary artist while suppressing duplicate releases of the same recording. In the results, Enter reviews the replacement. Tab to Replace, or use Replace playlist track from the candidate's context menu, to substitute it at the original playlist position. Find alternate versions is also available from other track context menus and from Playback, Now Playing. There, Enter plays the selected alternative without changing a playlist.

Exporting a list

Choose File, Export list to save the list you are viewing as a readable file. You are asked where to save it and whether it should be plain text or CSV. Each entry has its position, title, artist, album, duration and a Spotify link. CSV opens in a spreadsheet, including accented and Polish characters. Only this information is exported; no audio is downloaded.

The export contains exactly what is displayed, in that order, so a Filter this list or Sort by choice applies. In a list of playlists or albums, such as the Playlists tab, Export list exports the tracks of the selected one instead. If the list still ends with a row that loads more results, BlindSpot tells you the file is a partial list; load the rest and export again for everything. A chart from Discover exports too, without durations or links for songs not yet looked up on Spotify.

Albums

Choose Album and recording information from a track or album context menu. The read-only window includes Spotify's detailed release and recording metadata: release type and date, record label, copyrights, track and disc numbers, duration, explicit status, ISRC and UPC when available. The same command is under Playback, Now playing.

Press Ctrl+8 to browse albums saved in your Spotify library. Enter opens the selected album, and Backspace returns to the previous position. Use Ctrl+L to like or unlike the selected album.

When browsing an album, each row contains its track number and title, followed by any artist credited in addition to the album's primary artist. Multi-disc releases also include the disc number. Press Enter to play only the selected album track. Press F4 to play the album from the focused track.

Discover

Press Ctrl+9 to open Discover. The Discover radio buttons choose between New releases, Followed artists and authors, Apple Music most played and Charts. Only the control that applies to the chosen source stays enabled, and neither source replaces the current list until Search is activated again.

With New releases selected, choose Songs or Albums under Show, then a Genre, how recent a release must be under Released within, and a country, and activate Search. The list comes from Apple's iTunes Store chart for that genre and country, keeping only releases inside your window, newest first. Type an artist or title in the keyword box to list that artist's releases instead, for example a small Australian artist who does not chart. Keyword searches ignore the genre but still honour Released within, so choose Any time to see older releases. Releases are looked up on Spotify only when you act on them. Choose Followed artists and authors to see new releases by artists you follow and new audiobooks by authors you follow: right-click an artist, song, album or audiobook and choose Follow for new releases, or use Playback, Now playing, Follow artist or author for new releases for what is playing. Audiobook releases come from Apple's catalogue and only titles marked Unabridged or Abridged are listed, which skips translated editions; an audiobook opens in the Audiobooks tab if Spotify has it. Followed releases automatically use the country from your Spotify account, falling back to Australia when unavailable; the country picker is disabled for this workflow. Choose File, Followed artists and authors to review or remove them. BlindSpot also checks for new releases a few seconds after it starts and announces any it has not mentioned before; turn that off in Preferences. Enter opens a release, F4 plays it, and Ctrl+L saves or removes it from your library.

Apple Music most played lists the most played songs or albums, chosen under Show, in the country chosen under Chart country. The chart comes from Apple Music's public feed, so it reflects real listening across Apple Music's whole user base rather than a sample. Apple provides up to a hundred entries and all of them are listed at once. Every row announces its chart position, title, artist and year.

With Albums chosen, Enter resolves the album on Spotify and opens its tracks; F4 resolves and plays it.

Charts offers five sources, chosen under Chart. The US Billboard Hot 100 (experimental) accepts a date written as year-month-day, with or without hyphens, and loads the latest weekly chart on or before that date. BlindSpot reads the JSON live from the community-maintained mhollingshead/billboard-hot-100 project on GitHub. The source is unofficial, is not included with BlindSpot, and may change or disappear.

Triple J Hottest 100 enables a Countdown list containing annual polls and special countdowns such as Of Australian Songs, Like A Version and the all-time polls. Choose one explicitly before activating Search; BlindSpot prompts you if none is selected. Results come from the official ABC archive and show the countdown rank, artist, title and release year. It is a listener poll rather than an Australian sales chart, and community playlists are not used as chart data.

ABC Classic 100 enables a countdown list covering ABC Classic's themed annual listener polls from 2001 through the current poll. Rows contain the official rank, work and composer. When you play, queue or save a work, BlindSpot searches Spotify for a representative recording. For a symphony, concerto, opera or collection, the match may be one movement or excerpt rather than the complete work.

ABC Radio National Top Books enables a countdown list rather than the historical-date edit. It offers the official 2025 Top 100 Books of the 21st Century, The Ones That Got Away at ranks 101 to 200, and a combined Top 200. Rows contain the official rank, title and author. BlindSpot searches Spotify for an audiobook only when you open or play a row, so browsing the countdown does not use audiobook listening time. Spotify audiobook availability depends on your plan and country. Future ABC countdowns, including 2026 when published, can be added to this same list.

Number ones by country covers the United Kingdom, Australia and New Zealand, chosen under Number ones country. It accepts a year or a date in the same box. Type a year such as 1985 to list every number one that year, choosing Songs or Albums under Show. Each song is listed once, with its weeks at number one that year and, when it differs, in total. Order puts the song with the most weeks at number one first, which is the default, or lists them in date order. Type a full date such as 1985-07-13 to hear which single or album was number one in that chart week. Years available: United Kingdom singles from 1952 and albums from 1956; Australia singles from 1940 and albums from 1965; New Zealand singles and albums from 1980. The data comes from Wikipedia's lists of number ones, which are licensed CC BY-SA and compiled from each country's official charts. They list only number ones, not the whole chart, and being community edited they can contain mistakes.

BlindSpot does not search Spotify for chart entries when the chart appears. Each song or album is looked up only when you play it with Enter or F4, queue it, like it, add it to a playlist, open its album or menu, or start a similar-music mix from it. That takes a moment the first time and is announced. It keeps BlindSpot well inside Spotify's request limits. Until a song has been looked up the row cannot show Spotify details such as its duration or album, and BlindSpot cannot tell you in advance whether Spotify has it. If Spotify does not, you are told when you try to play or queue it. If Spotify refuses a lookup because of its request limit, BlindSpot says how long to wait.

Chart country starts on your Spotify account's country when Apple publishes a chart for it, and otherwise on Australia. Choosing a country yourself always takes precedence. The status line states the source and country, when BlindSpot loaded the chart, that Apple publishes rank only rather than play counts, a reporting period or a measurement time, and that songs are looked up on Spotify on demand. Apple's own updated stamp is not shown because it reflects when the chart was requested, not when it was measured.

A real chart mixes new releases with long-standing favourites, because listeners keep playing them. A song from decades ago appearing partway down the list is a genuine chart position, not a fault.

The Filter this list edit box and the View, Sort by submenu apply to whichever Discover results are loaded. Filtering never hides the row that loads the next page.

Concerts

Press Ctrl+Shift+G, or choose File, Search for concerts, to open the concert search window and search Ticketmaster for upcoming live events. Close the window with Escape; it keeps your last search. Choose a country and From and Until dates, then enter an optional keyword, state code or city, optionally choose a Ticketmaster category and genre, and activate Search concerts. Genres update to match the chosen category; leave both set to All for the broadest keyword search. BlindSpot lists up to 50 events at a time in date order. Choose Load more results to retrieve another page, or press Enter on a concert to open its official Ticketmaster page. Add your Ticketmaster Discovery API key in Preferences before searching. At the end of Preferences, choose Get a Ticketmaster API key to open Ticketmaster's registration instructions.

Lyrics

To translate fetched lyrics, open File, Preferences, enter a DeepL API key and choose a Lyrics translation language. BlindSpot automatically recognises API Free keys. BlindSpot does not translate each fetched song automatically. Activate Fetch translation in the Lyrics window when you want one. The button disappears after success and Translation is added to the Lyrics view choice. Translations are cached locally, so reopening the same lyrics does not submit them again or consume more translation credit.

Press Ctrl+Y to retrieve lyrics, either on a focused track, or a currently playing song. In the Lyrics window, press Ctrl+F on Windows or Command+F on macOS to show a Find box. Enter finds the next match and Shift+Enter finds the previous match. With focus back in the read-only lyrics, N and P repeat next and previous. Escape closes the Find box.

Select Follow playback on braille display to read the lyrics in real-time as the song plays. BlindSpot changes lines around 1 second early by default, giving you time to read the incoming line. Ctrl+Less-than moves changes 0.5 seconds earlier and Ctrl+Greater-than moves them 0.5 seconds later. Fine-tuning is saved separately for each Spotify song in data/lyrics.json. You can move the cursor to a line of a song, and press Shift+Space to start or resume audio playback from that line. Press Spacebar in the lyrics text, or F7, to pause or resume audio playback. Spacebar remains available normally for controls such as the follow-playback checkbox. Alt+Up Arrow and Alt+Down Arrow on Windows, or Option+Command+Up Arrow and Option+Command+Down Arrow on macOS, move to the previous or next synced lyric line and play the audio from that position. Select Enable phrase mode to have any of these commands pause playback when the next synced line begins. Phrase mode is off each time the Lyrics window opens. BlindSpot reports when synced lyrics are unavailable and if line seeking cannot be used.

On macOS, VoiceOver does not provide BlindSpot with a separate braille-only scripting channel. Following therefore uses a VoiceOver announcement, which may also speak each line. VoiceOver speech can be muted temporarily when braille-only reading is preferred. This macOS behaviour is experimental. The same 1-second lead and saved per-song fine-tuning apply.

Karaoke and instrumental tracks

BlindSpot has been programmed to display lyrics for Karaoke/instrumental versions of tracks too, so you can read the lyrics and sing along to your favourite songs! A synced result is accepted when its duration is within ten seconds of the original Spotify recording.

The matched lyric source is cached for that Spotify song in data/lyrics.json. Its timing adjustment is also song-specific, allowing a karaoke recording to be aligned once and reused later.

Playback devices

Press Ctrl+Shift+D, or choose playback device under the "Go" menu, to list the controllable Spotify Connect devices currently available on the account. After selecting a device, choose whether to continue playing there, move playback there without playing, or force a transfer on the next play command without moving the current session immediately. Moving without playing first pauses the current device, preserves the track and position, and leaves the destination paused. Choose BlindSpot from the same dialog to return playback to the internal player. Remote playback controls use Spotify's network service and may respond less quickly than the internal player. Devices marked as restricted by Spotify are not shown, and some devices do not support remote volume adjustment.

If a phone or speaker is missing, open Spotify on a linked account such as a mobile device, and start playback on that device first. For a Sonos, Google Cast, or similar speaker, transfer playback to the speaker from Spotify's phone app, leave it active, and then reopen BlindSpot's device picker. Spotify may report only devices that are active or have been used recently, and BlindSpot retrieves a fresh device list whenever the picker opens. Choose Refresh device list at the end of the picker after activating a phone or speaker.

Recently Played

Press Ctrl+5 to open Recently Played. The list loads when you move into it. Use Go, Refresh current view (Control+Shift+F) to refresh the tab's contents. Enter plays the selected track, and its context menu provides the usual album, queue, and library actions. The first time it is opened, BlindSpot may ask to authorize access to Spotify listening history. The list comes directly from Spotify and preserves Spotify's most-recent-first ordering.

Audiobooks

Press Ctrl+6 to open saved Spotify audiobooks. Enter opens a book and lists its chapters. Each chapter announces its saved Spotify resume position when one is available; Enter plays from that position. Backspace returns to the saved-book list.

Audiobook availability, included listening time, and playback are determined by the individual's Spotify plan.

Podcasts

Press Ctrl+7 to open Podcasts. Choose a category such as Comedy, News, Science or Technology, then activate Browse podcasts to explore matching Spotify shows. These are relevance-ranked Spotify search results, not a complete Spotify catalogue. Each show identifies its publisher; use its context menu for the description, or press Enter to browse episodes. Choose Show saved podcasts to return to followed shows and saved episodes.

Search offers Podcasts for matching whole shows and Podcast episodes for matching individual episodes. These searches fetch results in batches; choose Show more podcasts or Show more episodes to append another batch. Opening a podcast lists its first 50 episodes. Choose Show more episodes at the end of the list to continue browsing. BlindSpot retains the existing entries, moves focus to the first newly added episode, and announces how many were loaded.

Followed podcasts and saved episodes appear together when the saved view is selected. Episodes use their Spotify resume positions when available. Podcast views also provide language and listening-status filters. Language uses the metadata declared by Spotify. Listening status can be All, Not started, In progress, Completed, or Unknown; missing playback information remains Unknown. If more Spotify pages are available, filtered counts are labelled as covering loaded items.

Choose Download episode from a podcast episode's context menu to save its public RSS media file. BlindSpot locates the publisher's public feed independently of Spotify, so downloads may be unavailable for private or Spotify-exclusive episodes.

Sleep timer

Press Ctrl+Shift+J to activate the sleep timer dialog. BlindSpot can sleep after 15, 30, or 60 minutes. The timer controls BlindSpot's internal player as well as selected Spotify Connect devices.

Bookmarks

Press control+shift+b to bookmark a position whilst a song is playing. Press Ctrl+B, or choose File, Bookmarks, to open Bookmarks in its own window. Each entry includes its saved playback position. Press Enter to resume from that position, Delete to remove it, or use the context menu for resume, album, queue, library, and delete actions.

Bookmarks are stored locally in data/bookmarks.json in BlindSpot's portable folder. They are separate from Spotify's saved library and do not synchronize to other Spotify applications.

Preferences

Use File, Preferences to adjust settings such as speaking the track name whenever playback changes. Track-change announcements use the configured accessible-output2 screen-reader output and are disabled by default. Startup playback memory can either remember nothing, remember the last track from its beginning, or remember both the track and its elapsed position. Press F7 after the next launch to start the remembered track. BlindSpot also restores the last manually selected built-in-player volume when it starts again; temporarily muting playback does not replace that saved volume.

Language chooses the language of BlindSpot's menus, messages and spoken text. System default follows the language of your operating system when a translation exists; otherwise BlindSpot uses English. Restart BlindSpot after changing it. Polish is included; corrections are welcome. This manual is currently available in English only. Anyone can help to translate BlindSpot without programming; the translator guide is in the locale folder of the BlindSpot GitHub repository.

Choose Keyboard Manager from Preferences to change built-in shortcuts. All commands are shown initially; type in Search commands to filter by name, context, or assigned key. Commands are grouped into Main, Lists, and Lyrics contexts. Assign replaces the same key in its context, Clear removes a command's assignment, and Restore defaults resets the selected context. The same manager can assign opt-in global shortcuts to playback, seeking, Spotify volume, mute, current-track liking and announcements, time announcements, bookmarks, shuffle, and repeat commands. Global shortcuts work while BlindSpot is in the background and may override shortcuts in other applications. None are assigned by default, and existing global assignments are retained. If another application already owns a combination, BlindSpot reports that assignment but continues registering the others. BlindSpot stores custom keys in keymap.json and application settings. Brief conflict and global-risk warnings are shown only once.

Logging is off by default. It can be enabled when diagnostic information is needed.

Reporting a problem

When something goes wrong, the error message has a Copy error details button. Help, Copy last error details does the same at any time. The copied text says what BlindSpot was doing, the error type and message, any Spotify status and wait time, and the technical traceback. Tokens, API keys, e-mail addresses and your Windows user name are removed, and file locations are shortened.

For a developer report, choose Help, Capture log for developer. A window shows the whole report, which you can read before choosing Copy to clipboard or Save to file. It contains BlindSpot, Python and operating system versions, non-secret settings, whether each credential is set but never its value, and the last error.

Include recent log lines adds the end of the log. Song, artist and playlist names, device names and search terms are hidden there unless you also tick the box to include them. Logging is off by default: in Preferences set the logging level to Debug, repeat the problem, then create the report. Read the report before sharing it, since a log can still reveal what you were listening to when names are included.

Portable data

On Windows, settings, authentication, and logs are stored in the data folder beside BlindSpot. Use File, Account, Sign out and erase credentials before sharing the portable folder.

On macOS, BlindSpot uses Library/Application Support/BlindSpot in the current user's home folder. Authentication remains available when BlindSpot.app is moved or updated.

This application is unsigned. After extracting the download, open Terminal in the BlindSpot-macOS folder and run sh prepare-macos.sh. The helper changes the adjacent BlindSpot.app, removes its downloaded quarantine attribute, and opens it. It does not require administrator access.

Updates

BlindSpot checks its GitHub release feed when it starts. When a newer build is available, it offers to install it. Portable Windows builds preserve the data folder, replace the program after it closes, and restart automatically. macOS opens the release page because a running app bundle cannot safely replace itself. Use Help, Check for updates to check on demand.
