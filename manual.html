BlindSpot manual

Build 2026.7.0.6

BlindSpot is a portable, keyboard-first Spotify client for Windows and macOS.

Main interface

Use Tab and Shift+Tab to move throughout the interface. Enter opens an album, artist, playlist, or podcast, and plays a track or episode. Backspace returns to the previous remembered list position. A horizontal tab-bar, as well as a menu bar, is where the program's features are located

Keyboard commands

  • Ctrl+1 through Ctrl+8: Search, Liked Songs, Queue, Playlists, Recently Played, Bookmarks, Audiobooks, and Podcasts respectively.
  • Ctrl+Tab and Ctrl+Shift+Tab: cycle through the main tabs.
  • Ctrl+F: focus the search box.
  • Ctrl+Comma: open Preferences.
  • Enter: open a container, or play a track or episode.
  • F4: play the focused track, playlist, album, or artist.
  • F5 / F6: seek backward and forward five seconds.
  • F7: restart the current track after the half-second double-press window. Press twice within that window to move to the previous track immediately.
  • F9: next track.
  • F8: pause or resume. After launch, F8 also starts a remembered track when playback memory is enabled.
  • Ctrl+F5 / Ctrl+F6: decrease and increase volume by five percent.
  • Ctrl+F4: mute or restore the previous volume.
  • Space: pause or resume playback, except when focus is in a control that uses Space itself, such as a button, radio button, checkbox, or edit field.
  • Ctrl+Space: play from the current line in Lyrics. Elsewhere, mark or unmark the focused list item.
  • Ctrl+Q: queue selected track or tracks.
  • Ctrl+L: like or unlike selected track.
  • Ctrl+Shift+A: add selected track to a playlist.
  • Ctrl+Shift+N: create playlist.
  • Ctrl+Shift+B: bookmark current playback position.
  • Ctrl+R: cycle repeat mode.
  • Ctrl+S: toggle shuffle.
  • Ctrl+J: jump to playback time.
  • Ctrl+Shift+J: open sleep timer.
  • Ctrl+Shift+I: speak current track name.
  • Ctrl+Shift+U: speak upcoming track.
  • Ctrl+Y: retrieve lyrics for the focused playable item, or for the current track when focus is elsewhere.
  • Ctrl+Shift+T: speak total track time.
  • Ctrl+Shift+E: speak elapsed time.
  • Ctrl+Shift+R: speak remaining time.
  • Delete: remove the selected playlist, or track from Liked Songs.
  • Delete inside a playlist: remove the selected track when editable.
  • Backspace or Alt+Left: return to the previous remembered view.
  • Shift+F10 or the Applications key: open item actions.

Search results

A category search initially displays up to 20 results. When Spotify has more matches, activate Load more results at the end of the list to append the next page. All-category searches use smaller pages for each content type so their results remain balanced.

Playlists

Followed playlists that cannot be edited are announced as read only. Enter opens a focused playlist. F4 plays the focused playlist, or starts at the focused song when browsing inside one. A song started from inside a playlist continues through that playlist.

Use Ctrl+Space to mark more than one song and Ctrl+Q to add all marked songs to the queue in list order. Delete removes the focused song from an editable playlist. At the main playlist list, Delete removes the focused playlist from your library after confirmation.

The playlist context menu provides Open, Play, New playlist, Rename for playlists you own, and Remove from library.

Albums

When browsing an album, each row contains only its track number and title, followed by any artist credited in addition to the album's primary artist. Multi-disc releases also include the disc number. The context menu does not repeat the Open album action while that album is already open. Press F4 on an album track to start it within the album context. F4 on track 1 plays the album from beginning to end.

Lyrics

Press Ctrl+Y to retrieve lyrics, either on a focused track, or a currently playing song.

Select Follow playback on braille display to read the lyrics in real-time as the song plays. BlindSpot changes lines around 1 second early by default, giving you time to read the incoming line. Ctrl+Less-than moves changes 0.5 seconds earlier and Ctrl+Greater-than moves them 0.5 seconds later. Fine-tuning is saved separately for each Spotify song in data/lyrics.json. You can move the cursor to a line of a song, and press Ctrl+Space to start or resume audio playback from that line. Press Spacebar in the lyrics text, or F8, to pause or resume audio playback. Spacebar remains available normally for controls such as the follow-playback checkbox. Ctrl+Up Arrow and Ctrl+Down Arrow move to the previous or next synced lyric line and play the audio from that position. BlindSpot reports when synced lyrics are unavailable and if line seeking cannot be used.

On macOS, VoiceOver does not provide BlindSpot with a separate braille-only scripting channel. Following therefore uses a VoiceOver announcement, which may also speak each line. VoiceOver speech can be muted temporarily when braille-only reading is preferred. This macOS behaviour is experimental. The same 1-second lead and saved per-song fine-tuning apply.

Karaoke and instrumental tracks

BlindSpot has been programmed to display lyrics for Karaoke/instrumental versions of tracks too, so you can read the lyrics and sing along to your favourite songs! A synced result is accepted when its duration is within ten seconds of the original Spotify recording.

The matched lyric source is cached for that Spotify song in data/lyrics.json. Its timing adjustment is also song-specific, allowing a karaoke recording to be aligned once and reused later.

Playback devices

Choose playback device under the "Go" menu lists the controllable Spotify Connect devices currently available on the account. Selecting a device transfers and starts playback. Choose BlindSpot from the same dialog to return playback to the internal player. Remote playback controls use Spotify's network service and may respond less quickly than the internal player. Devices marked as restricted by Spotify are not shown, and some devices do not support remote volume adjustment.

If a phone or speaker is missing, open Spotify on a linked account such as a mobile device, and start playback on that device first. For a Sonos, Google Cast, or similar speaker, transfer playback to the speaker from Spotify's phone app, leave it active, and then reopen BlindSpot's device picker. Spotify may report only devices that are active or have been used recently, and BlindSpot retrieves a fresh device list whenever the picker opens.

Recently Played

Press Ctrl+5 to open Recently Played. The list refreshes whenever the tab is opened. Enter plays the selected track, and its context menu provides the usual album, queue, and library actions. The first time it is opened, BlindSpot may ask to authorize access to Spotify listening history. BlindSpot also keeps a local record of confirmed playback, so tracks started from playlists are retained even when Spotify's history feed is delayed or omits them. This local history is stored in data/recently_played.json.

Audiobooks

Press Ctrl+7 to open saved Spotify audiobooks. Enter opens a book and lists its chapters. Each chapter announces its saved Spotify resume position when one is available; Enter plays from that position. Backspace returns to the saved-book list.

Audiobook availability, included listening time, and playback are determined by the individual's Spotify plan.

Podcasts

Search offers Podcasts for matching whole shows and Podcast episodes for matching individual episodes. Audiobooks is also available as a separate search category. Opening a podcast lists all of its episodes, including additional pages beyond the first 50.

Press Ctrl+8 to browse saved podcasts and saved episodes. Episodes announce and use their Spotify resume positions when available. Use an item's context menu and choose Description to read the description supplied by its publisher or creator. Spotify does not identify descriptions as automatically generated. Choose Download episode from a podcast episode's context menu to save its public RSS media file. BlindSpot locates the publisher's public feed independently of Spotify, so downloads may be unavailable for private or Spotify-exclusive episodes.

Sleep timer

Press Ctrl+Shift+J to activate the sleep timer dialog. BlindSpot can sleep after 15, 30, or 60 minutes. The timer controls BlindSpot's internal player and selected Spotify Connect devices. The same submenu cancels an active timer. After current track uses a local deadline corrected by ordinary playback updates; it does not increase Spotify Connect polling.

Bookmarks

Use Go, Bookmark current position while a track is playing, or choose Bookmark current position from that track's context menu. Press Ctrl+6 to open Bookmarks. Each entry includes its saved playback position. Press Enter to resume from that position, Delete to remove it, or use the context menu for resume, album, queue, library, and delete actions.

Bookmarks are stored locally in data/bookmarks.json in BlindSpot's portable folder. They are separate from Spotify's saved library and do not synchronize to other Spotify applications.

Preferences

Use Options, Preferences to adjust settings such as speaking the track name whenever playback changes. Track-change announcements use the configured accessible-output2 screen-reader output and are disabled by default. Startup playback memory can either remember nothing, remember the last track from its beginning, or remember both the track and its elapsed position. Press F8 after the next launch to start the remembered track.

Choose Configure global keyboard shortcuts to assign any desired combination separately to previous, pause/resume, next, seek, volume, or mute. No global shortcuts are assigned by default. An assignment works while BlindSpot is in the background and may override the same command in another application. If another application already owns a combination, BlindSpot reports that assignment but continues registering the others.

Logging is off by default. It can be enabled when diagnostic information is needed.

Portable data

Settings, authentication, and logs are stored in the data folder beside BlindSpot. Use Options, Account, Sign out and erase credentials before sharing the portable folder.

On macOS, BlindSpot uses a data folder beside BlindSpot.app when that location is writable. If the app is installed in a read-only location, BlindSpot uses Library/Application Support/BlindSpot in the current user's home folder instead.

This application is unsigned. After extracting the download, open Terminal in the BlindSpot-macOS folder and run sh prepare-macos.sh. The helper changes the adjacent BlindSpot.app, removes its downloaded quarantine attribute, and opens it. It does not require administrator access.

Updates

BlindSpot checks its GitHub release feed when it starts. When a newer build is available, it offers to install it. Portable Windows builds preserve the data folder, replace the program after it closes, and restart automatically. macOS opens the release page because a running app bundle cannot safely replace itself. Use Help, Check for updates to check on demand.
